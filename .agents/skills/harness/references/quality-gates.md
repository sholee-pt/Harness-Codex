# 품질 기준

## 구현 작업

- 요구사항의 각 항목이 실제 변경과 연결되어 있습니다.
- 관련 테스트나 검사 결과가 성공했습니다.
- 오류 처리와 경계 조건을 확인했습니다.
- 사용자 변경사항과 무관한 파일을 덮어쓰지 않았습니다.
- 배포, 외부 메시지, 병합 같은 범위 밖 변경이 없습니다.

## 코드 리뷰

- 발견 사항마다 재현 가능한 근거와 파일 위치가 있습니다.
- 단순한 취향과 실제 결함을 구분했습니다.
- 보안, 데이터 손실, 호환성, 테스트 공백을 우선 확인했습니다.
- 문제가 없으면 없다고 명확히 말하고, 남은 검증 공백을 별도로 적습니다.

## 최종 보고

- 완료 결과를 첫 문단에 제시합니다.
- 실행한 검증과 실행하지 못한 검증을 구분합니다.
- 남은 위험과 다음 결정이 필요한 항목만 간결하게 남깁니다.
